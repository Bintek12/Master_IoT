# Master_IoT
Pantalla TFT Máster para revisar y controlar y supervisar 1-La Energía Eléctrica, Proveniente de sistema foto-voltaico con almacenamiento 2-El abastecimiento de Agua.  
El sistema de Energía Eléctrica esta embebido en un ATMEGA168A con seguimiento solar para mxima eficiencia en la produccion de energia y el control del Agua esta embebido en un ESP8266 con sistemas de protecion contra ausencia de flujo y calculos de Gasto/Reserva.
Ambos sistemas por protocolo MODBUS RS485 como esclavos, aportan a información para el Master IoT ATXMEgA32UA4 con pantalla TFT de Ledoelectronics.com
